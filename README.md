# LaslesVPN — صفحه فرود (Landing Page) با React

یک صفحه فرود کامل برای یک سرویس VPN به نام **LaslesVPN**، ساخته‌شده با **React 18** و
طراحی‌شده بر اساس تصویر مرجع (طرح ردوگرا/سفید با دکمه‌های گرادیانی).

> ✅ **بدون بک‌اند** — هیچ سرور، دیتابیس یا API نیاز نیست.
> ✅ **بدون مرحله Build** — React و Babel به‌صورت لوکال در پوشه `vendor/` قرار دارند و پروژه کاملاً آفلاین اجرا می‌شود.
> ✅ **واکنش‌گرا (Responsive)** — هم روی دسکتاپ/لپ‌تاپ و هم روی موبایل و تبلت قابل استفاده است.

## 🌐 مشاهدهٔ آنلاین (منتشرشده با ngrok)

آدرس عمومی پروژه:

**<https://unplowed-outskirts-herself.ngrok-free.dev>**

> این آدرس تا زمانی که تونل ngrok روی سیستم باز باشد فعال است. برای اجرای دوبارهٔ تونل، فایل
> `publish-ngrok.cmd` را دوبار کلیک کنید (پایین‌تر توضیح داده شده است).

## اجرای پروژه

چون فایل‌های `jsx` در مرورگر کامپایل می‌شوند، صفحه باید از طریق یک **وب‌سرور ساده** باز شود
(باز کردن مستقیم فایل با `file://` کار نمی‌کند). سه راه ساده:

### ۱) ویندوز — دوبار کلیک روی فایل راه‌انداز
فایل `serve.cmd` را اجرا کنید. سرور بالا می‌آید و مرورگر خودکار باز می‌شود.

### ۲) با Python (روی این سیستم نصب است)
```powershell
cd F:\MyFirstWebsite
python -m http.server 8123 --bind 127.0.0.1
```
سپس در مرورگر: <http://127.0.0.1:8123/index.html>

### ۳) با Node.js (اختیاری)
```bash
npx --yes serve . -l 8123
```
یا در VS Code از افزونه **Live Server** استفاده کنید.
(توجه: `npm install` لازم نیست؛ پروژه به هیچ پکیجی وابسته نیست.)

## انتشار روی اینترنت با ngrok

برای اینکه صفحه یک **آدرس عمومی** داشته باشد (قابل باز شدن روی موبایل و برای دیگران):

1. فایل `publish-ngrok.cmd` را دوبار کلیک کنید.
   - اگر سرور محلی بالا نباشد، خودش `python -m http.server 8123` را اجرا می‌کند.
   - بار اول، توکن حساب رایگان ngrok را می‌پرسد (از
     <https://dashboard.ngrok.com/get-started/your-authtoken>).
2. آدرس `Forwarding` (مثل `https://xxxx.ngrok-free.dev`) را کپی و به اشتراک بگذارید.
   همین آدرس در پنل محلی <http://127.0.0.1:4040> هم دیده می‌شود.
3. برای خاموش کردن انتشار، در همان پنجره `Ctrl+C` بزنید.

آدرس فعلی این پروژه: **<https://unplowed-outskirts-herself.ngrok-free.dev>**

> در پلن رایگان، هر بار اجرای ngrok آدرس تغییر می‌کند (مگر با حساب خود یک دامنه/static domain
> رزرو کنید). صفحهٔ واسط «Visit Site» هم فقط مربوط به پلن رایگان است.

## بخش‌ها و قابلیت‌ها

| بخش | توضیح |
|---|---|
| نوار بالا | لوگو، منوی About/Features/Pricing/Testimonials/Help، دکمه‌های Sign In و Sign Up (گرادیان قرمز) — روی موبایل منوی همبرگری |
| هیرو | تیتر، توضیح، دکمه Get Started و تصویر `src/assets/Illustration 1.png` |
| آمار | کارت سفید با سایه شامل Users / Locations / Servers (آیکون‌های دایره‌ای صورتی) |
| ویژگی‌ها | تصویر `src/assets/Illustration 2.png` سمت چپ + تیتر و ۴ مزیت با تیک سبز؛ تیک‌ها و متن‌ها در همهٔ عرض‌ها زیر هم قرار می‌گیرند |
| انتخاب پلن | سه کارت Free / Standard / Premium با تصویر `Free.png` / `Standard.png` / `Premium.png`؛ **کلیک روی هر کارت یا دکمه Select آن پلن را انتخاب می‌کند** (پیش‌فرض: Premium) |
| شبکه جهانی | نقشهٔ واقعی `src/assets/Huge Global.png` با ۱۶ پین قرمز + انیمیشن پالس روی چند پین |
| نظرات | کارت‌های مشتریان با عکس‌های واقعی (`Viezh Robert.png`, `Yessica Christy.png`, `Kim Young Jou.png`)، امتیاز ۴.۵ و اسلایدر (دات‌ها + فلش قبلی/بعدی) |
| اشتراک | کارت «Subscribe Now» با دکمه گرادیانی و شکل تزئینی خاکستری پشت آن |
| فوتر | معرفی کوتاه، شبکه‌های اجتماعی، کپی‌رایت و سه ستون لینک |

### تعامل‌ها (بدون بک‌اند، فقط State در React)
- **انتخاب پلن**: با کلیک روی کارت یا دکمه‌ی `Select` پلن فعال می‌شود (حاشیه قرمز + دکمه گرادیانی + تیک) و برای صفحه‌خوان‌ها متن «Selected plan: ...» اعلام می‌شود (متن روی صفحه نمایش داده نمی‌شود تا طرح دقیقاً مثل تصویر مرجع بماند).
- **اسلایدر نظرات**: اسلایدر واکنش‌گرا؛ با فلش‌ها یا نقطه‌ها جابه‌جا می‌شود (کارت فعال با حاشیه قرمز مشخص است).
- **منوی موبایل**: دکمه همبرگری، بستن با کلیک روی هر لینک.
- **اسکرول**: نوار بالا هنگام اسکرول سایه می‌گیرد؛ لینک‌های منو با اسکرول نرم به بخش‌ها می‌روند.

## سفارشی‌سازی سریع

| می‌خواهم... | کجا |
|---|---|
| متن‌ها، پلن‌ها، نظرات و لینک‌های فوتر را عوض کنم | `src/data/content.js` |
| رنگ برند را عوض کنم | `src/styles.css` → `:root` (متغیرهای `--red`, `--grad-red`, `--dark`, ...) |
| فاصله‌ها و اندازه‌ها را تغییر دهم | `src/styles.css` (متغیر `--container`, کلاس‌های `.section`) |
| تصویرسازی‌ها را تغییر دهم | `src/assets/` (تصاویر واقعی طرح) و برای لوگوهای برند `src/components/Illustrations.jsx` |
| آیکون‌ها را عوض کنم | `src/components/Icons.jsx` |
| یک بخش جدید اضافه کنم | یک فایل در `src/components/` بسازید، در `src/App.jsx` استفاده کنید و در `index.html` هم به لیست اسکریپت‌ها اضافه کنید |

### نکته مهم دربارهٔ نحوهٔ بارگذاری فایل‌ها
پروژه عمداً «بدون Build» است: هر فایل `jsx` با `<script type="text/babel">` در `index.html`
بارگذاری می‌شود و Babel آن را در مرورگر کامپایل می‌کند. بنابراین:

- همهٔ کامپوننت‌ها در **اسکوپ عمومی** تعریف می‌شوند (بدون `import`/`export`).
- **ترتیب اسکریپت‌ها در `index.html` مهم است**: `content.js` → `Icons` → `Illustrations` → کامپوننت‌ها → `App.jsx` → `main.jsx`.
- اگر فایل جدیدی اضافه می‌کنید، حتماً قبل از `App.jsx` آن را در `index.html` قرار دهید.

## ریسپانسیو (دسکتاپ + موبایل)

- **دسکتاپ (≥ 992px)**: چیدمان دو ستونه، سه کارت پلن کنار هم، اسلایدر سه کارتی.
- **تبلت (≤ 992px)**: منوی همبرگری، تصاویر زیر متن، کارت‌های آمار عمودی (آیکون/عدد/برچسب همه در یک ستون هم‌تراز)، کارت‌های پلن تک‌ستونه.
- **موبایل (≤ 620px)**: اندازه‌های تیتر/دکمه‌ها کوچک‌تر، نقشه با پین‌های ریزتر، لوگوی برندها دو ستونه، فوتر دو ستونه، اسلایدر با کارت باریک‌تر.
- انیمیشن‌ها برای کاربرانی که `prefers-reduced-motion` را فعال کرده‌اند غیرفعال می‌شوند.
